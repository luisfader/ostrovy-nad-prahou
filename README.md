# Ostrovy nad Prahou — Robert Fader

Román v češtině pro studenty na úrovni **A2–B1**. Pokračování příběhu učebnice **„Do podzemí!“**.

Lucie a Mark odjíždějí na dovolenou do Číny. Luis a Jana zůstávají v Praze sami. Po romantické noci u Vltavy se ráno nad městem objeví pět kamenných ostrovů s černými hrady, ukotvených řetězy v pěti srdcích Prahy.

Číst online: https://luisfader.github.io/ostrovy-nad-prahou/

## Struktura

```
index.html                         celý web (sestavení není potřeba)
novels/catalog.json                název, popis a seznam kapitol
novels/ostrovy-nad-prahou/         jeden soubor .md na kapitolu (01.md, 02.md, …)
```

## Přidat kapitolu

1. Vytvořit soubor `novels/ostrovy-nad-prahou/05.md`.
2. Přidat ho do `novels/catalog.json` do seznamu `chapters`.

Formát textu: odstavce oddělené prázdným řádkem, `*kurzíva*`, `**tučně**`, `***` — změna scény.
